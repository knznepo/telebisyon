Play with RetroArch

  1. On the TV, open RetroArch.
  2. Go to Settings → Network and turn on Network Commands (for Menu) and Network RetroPad.
  3. Below it, turn on User 1 Network RetroPad. For a second phone, also turn on User 2, and so on.
  4. Close RetroArch and open it again, so it saves the settings and starts listening. Then load a game.

Pick the controller that matches the game's console. For PlayStation games that use the sticks, open the game's Quick Menu → Controls → Port 1 Controls and set Device Type to DualShock.

Mobile (tilt to move) plays like a phone game: lean the phone to move, and press the buttons. Tap the circle to set the way you hold it as the middle. The button under it picks what tilt moves: the D-pad (most games) or the stick (N64 and PlayStation games). Phones only allow tilt on a secure page, so the first tap opens the TV's own one: if the browser warns that it isn't private, tap Advanced, then Proceed.

Menu, at the top, opens RetroArch's Quick Menu in a game: Resume goes back to it, Close Content ends it, and Save State keeps your place. Press it again to close the menu.

On a computer, the keyboard works too: arrows, Z X A S for the buttons, Q W for the shoulders, Enter for Start, Shift for Select and Esc for Menu.
